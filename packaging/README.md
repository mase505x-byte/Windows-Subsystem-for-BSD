# Building a WSB package

From the repository root, run:

```sh
bash packaging/build-package.sh
```

The builder runs the Rust workspace tests, builds the Rust release artifacts and
CMake CLI, then creates a host-specific `dist/wsb-0.2.0-<os>-<arch>.tar.gz`
archive and (when `sha256sum` or `shasum` is available) a SHA-256 sidecar.

`binaric.list` is the package metadata descriptor. The script stages the built
`wsb` CLI, `wsb-asm` library artifacts produced by Cargo, and project metadata;
it does not alter or regenerate source files. A separate CMake configure/build
step is intentional because the existing CMake project builds the CLI while
Cargo builds the Rust workspace.

The repository's `wsb-asm` crate generates byte buffers and ABI stub bytes only;
it does not decompile files, emit source assembly, allocate executable memory,
or run generated bytes. Therefore this package builder does not attempt to
reconstruct missing/broken source functions. The package is a build artifact
bundle, not a BSD runtime: the shell and server are not bundled or implemented
in the current repository.
